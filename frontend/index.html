How it reconciles
Three independent sources, one deterministic engine — the classification is never a model's guess.
01 — Sources
Ledger · Settlement · Bank
Three independent records of the same money: what you expected, what Razorpay actually paid out, and what hit the bank.
→
02 — Reconcile
Recompute the waterfall
Gross → refund → fee → GST → TDS → transfer, recomputed at contracted rates and diffed against actuals. Pure arithmetic, no model involved.
→
03 — Classify
8 rule-based exception types
Every category maps to an explicit, inspectable rule. Confidence is measured from pattern recurrence in the batch, not asserted by a model.
→
04 — Explain
AI narrates, never decides
Claude turns an already-verified finding into plain English on request. It cannot change the classification or the numbers.
Why this order matters: verification (steps 02–03) is where trust is won or lost, so it stays 100% deterministic and auditable. The model only appears at step 04, explaining a finding that's already been proven correct — never deciding what's true.
